# Lottie & Animated Sticker Assets

Place your animation files here. The bot will automatically detect and play them when available!

### Supported File Formats:
1. **Telegram Animated Stickers (`.tgs`)** — Telegram's native gzip-compressed Lottie format.
2. **GIF animations (`.gif`)** — Standard animated GIFs.
3. **MP4 animations (`.mp4`)** — Short looping video clips.
4. **Lottie files (`.json` or `.lottie`)**

### Recommended File Names:
- `searching.tgs` / `searching.gif` / `searching.mp4` — Played while searching & filtering for campus matches.
- `match_found.tgs` / `match_found.gif` / `match_found.mp4` — Played when a student candidate profile is found.
- `chat_start.tgs` / `chat_start.gif` / `chat_start.mp4` — Played when tapping [💬 Start Chatting].
- `welcome.tgs` / `welcome.gif` / `welcome.mp4` — Played on `/start` or profile completion.
